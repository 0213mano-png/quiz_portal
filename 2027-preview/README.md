## 教育設計の基本方針
1. 既存の講義・確認テスト・模擬試験のスケジュールは原則維持する。
2. 追加の必須テスト・事前事後テスト・提出物を設けない。
3. ○×暗記シートの10問モードは任意の復習手段として扱う。
4. 最初の段階では画面上の出題範囲（前半・後半・模擬試験）を本人が選ぶ。運営者が個人別の学習状況を集約する仕組みは追加しない。
5. 受験者の負担と講師・運営者の更新作業を増やさない。
